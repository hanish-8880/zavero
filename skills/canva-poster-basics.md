## Screen names
- Home search: type "Birthday Poster" to open Templates
- Left panel: Design, Elements, Text, Draw, Projects
- Center canvas: drag, resize, edit your poster pages
- Top bar: Share, Download, Resize, Undo / Redo
- Browser fix: use Chrome, Firefox, Safari (macOS only), Edge latest
- Desktop fix: Download for Windows 10 or later
- Mobile fix: get Canva for Android or iOS, or learn more about Canva
## Shortcuts
- Ctrl / Cmd + Z: undo last change
- Ctrl / Cmd + C / V: copy and paste text or object
- Ctrl / Cmd + D: duplicate selected element
- T: add a new text box fast
- Del / Backspace: delete selected item
## Good beginner choices
- Start with Birthday Poster template, then change name and photo
- Use Text > Add a heading for big name and date
- Use Elements > Stickers for balloons, cake, confetti
- Keep 2 fonts and 2-3 colors for clean look
- Use Projects auto-save so you do not lose work
## Common mistakes
- Old unsupported browser: upgrade to Chrome, Firefox, Safari, Edge
- Blurry print: choose Download > PDF Print or PNG high quality
- Text unreadable: increase size and contrast with background
- Wrong item moves: click to select, then Position > Forward / Backward
- Typos in name / date: proofread before downloading
## Steps that need approval
- Paying for Pro / Premium elements, fonts, stock photos
- Publishing with Share > public link or website
- Submitting to print: confirm size, copies, and cost
- Sharing personal data: full name, address, phone, party location
- Installing software: Download for Windows 10 or later
